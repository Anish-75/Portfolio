# Anish Gawade — Portfolio

A responsive, blue-themed portfolio built with plain HTML, CSS, and JavaScript. It is designed to deploy directly to GitHub Pages without a framework or build step.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- Inter via Google Fonts

Before publishing, add the `Anish-Gawade-CV.pdf` file and replace the `TODO` project links in `index.html` with the correct URLs.
